# Trần Yến (YenFinTechAI-Dev) — Personal Portfolio

Trang web giới thiệu cá nhân, năng lực kỹ thuật và các dự án **FinTech, Applied AI, Data Engineering & Blockchain** của **Trần Yến** (`YenFinTechAI-Dev`).

## Highlights

- **Dual Theme (Dark / Light)** lấy cảm hứng từ hệ màu tối/sáng độ tương phản cao (`#090909` / `#f8fef6`) với điểm nhấn xanh chanh (`#85d840`).
- **Song ngữ Việt – Anh (VI / EN)** chuyển đổi tức thì.
- **Bento Showcase & Case Study Modal** cho các dự án tiêu biểu: *GIV Charity*, *DataForge*, *AI-FINVEST-ADVISOR*, *E-Commerce Data Warehouse*, *VesperSignal News*, *LLMs RAG System* cùng bảng tổng hợp các kho GitHub công khai.
- **Interactive Architecture Lab** trình bày 4 trụ cột kỹ thuật kèm bản mẫu kiến trúc sao chép nhanh.
- **Responsive & Accessible** tối ưu cho cả desktop và thiết bị di động.

## Tech Stack

- React 19 + TypeScript
- Vite + Tailwind CSS v4
- Lucide React Icons

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
